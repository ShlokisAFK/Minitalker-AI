# Minitalker-AI
Local AI assistant running on Raspberry Pi using TinyLlama, Flask backend, animated chat UI, and custom prompt-engineered personality.

🧠 Minitalker-AI
Personal Local AI Assistant Running on Raspberry Pi

Minitalker-AI is a lightweight, fully local AI assistant built using a Raspberry Pi 5, a TinyLlama Chat LLM, a Flask backend, and a modern ChatGPT-style HTML frontend.

It is accessible through a custom domain using NGINX + Cloudflare, features a clean animated UI with typing indicators, auto-expanding input, and a custom-tuned personality.
